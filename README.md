# Minimal Ivory & Gold Nikkah

A responsive Pakistani nikkah invitation concept for Noor and Zayn.

## Preview locally

Open PowerShell in this folder and run:

```powershell
npm.cmd install --cache .npm-cache
npm.cmd run dev
```

Then open the local address shown in the terminal.

## Production build

```powershell
npm.cmd run build
```

The optimized website is created in `dist`.

## Included interactions

- animated folio opener with reduced-motion support
- responsive editorial layouts
- add-to-calendar download
- copyable venue address
- Google Maps venue link
- live wedding countdown
- accessible RSVP dialog and confirmation
